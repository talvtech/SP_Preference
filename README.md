# SP喜好小瓶子

一个用于填写和分享 SP 喜好的轻量网页工具。采用原生 HTML、CSS 和 JavaScript 实现，无需后端、安装依赖或构建，支持手机和电脑浏览器。

## 功能

- 点击瓶子依次切换：空 → 低 → 中 → 高 → 满 → 拒绝 → 空。
- 用自然堆积的星星呈现喜好程度，满档带有星星喷出的效果。
- 通过双端滑轨选择程度范围。
- 在各分类末尾添加自定义瓶子，支持删除。
- 自动在当前浏览器保存填写内容，支持一键清空。
- 导出 PNG 图片，手机优先打开系统保存菜单，不支持时提供长按保存，电脑直接下载；每行 5 个瓶子，各分类内按满、高、中、低、拒绝、空排序。

## 使用

下载项目，保持 `index.html`、`style.css` 和 `script.js` 在同一目录，直接用浏览器打开 [index.html](./index.html) 即可。也可以将这三个文件一起放到静态网站托管服务上访问。

填写完成后点击“保存图片”。手机端优先直接打开系统菜单，在菜单中选择“存储图像”或“保存图像”；系统分享不可用时会显示图片，长按即可保存。电脑端直接下载 PNG。导出排序不会改变填写页面的顺序。

系统文件分享需要浏览器支持，并建议通过 HTTPS 地址访问；不支持时可长按图片保存。网页会在手机停止编辑后准备图片，尽量让点击保存直接打开系统菜单；若刚修改完就立即保存且点击授权已失效，会提示再点一次同一按钮。

## 技术特点

使用原生浏览器 API，无第三方依赖和构建步骤，无需后端。使用 `localStorage` 保存数据，通过 SVG 绘制瓶子和星星，通过 Canvas 生成 PNG。

## 文件结构

```text
├── index.html  # 页面结构、操作按钮和对话框
├── style.css   # 主题、布局、响应式样式
├── script.js   # 默认题库、填写交互、本地保存、图片绘制与导出
└── README.md   # 项目说明
```

填写内容仅保存在当前浏览器中；清理浏览器数据后可能丢失。
