# SP喜好小瓶子

一个用于填写和分享 SP 喜好的轻量网页工具。采用单文件 HTML 实现，无需后端、安装依赖或构建，支持手机和电脑浏览器。

## 功能

- 点击瓶子依次切换：空 → 低 → 中 → 高 → 满 → 拒绝 → 空。
- 用自然堆积的星星呈现喜好程度，满档带有星星喷出的效果。
- 通过双端滑轨选择程度范围。
- 在各分类末尾添加自定义瓶子，支持删除。
- 自动在当前浏览器保存填写内容，支持一键清空。
- 直接下载 PNG 图片，每行 5 个瓶子，各分类内按满、高、中、低、拒绝、空排序。

## 使用

下载 [index.html](./index.html)，直接用浏览器打开即可，也可以放到静态网站托管服务上访问。

填写完成后点击“保存图片”下载 PNG。导出排序不会改变填写页面的顺序。

## 技术特点

HTML、CSS、JavaScript 与 SVG 全部内嵌在 `index.html` 中，无外部依赖和网络请求。使用 `localStorage` 保存数据，通过 Canvas 生成 PNG。

填写内容仅保存在当前浏览器中；清理浏览器数据后可能丢失。
